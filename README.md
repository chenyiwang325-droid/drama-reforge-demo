# 短剧出海逐分镜重制智能体

将中文短剧按分镜粒度自动转化为面向海外市场的本地化版本。用户输入短剧 ID 并指定目标市场方向（欧美 / 日韩 / 东南亚），系统自动完成角色、场景、对白的本地化适配与视频重制，经人工审核确认后输出海外版成片。

## 界面说明

### 0. 项目列表

创建与管理项目，展示项目卡片与解析进度。

- 项目卡片：名称、集数、角色/场景数、目标市场标签、解析进度条
- 创建项目：填写项目名称 + 短剧ID 创建新项目
- 预分析状态：未分析项目显示引导页、0% 进度条和待填充统计卡片，顶部按钮始终可见
- 项目删除

### 1. 项目界面

全集分析入口，查看逐集解析状态。

- 统计概览：总集数、角色数、场景数、分镜片段总数
- 全集介绍文本：自动生成的全剧剧情概述，支持编辑
- 转化方向选择：欧美 / 日韩 / 东南亚
- 逐集解析状态看板：可视化展示每集解析进度
- 全集分析按钮：顶部通用入口，触发分析流程

### 2. 资产库界面

四个子 Tab：角色 / 场景 / 道具 / 分镜，均支持按集数筛选。

**通用功能**：全选、按集数筛选、批量本地化转化、新增资产、添加本集资产、关键词搜索、删除条目

**角色**：可编辑中文名、转化名称、原始外观、转化外观。点击展开显示全部服装列表，每套服装展示原始中文描述和转化英文描述，编辑按钮对齐在卡片底部。支持新增和删除服装。

**场景**：可编辑中文名、转化名称、原始空间描述、转化空间描述。点击展开显示全部状态列表，每个状态展示原始描述和转化描述，编辑按钮对齐在卡片底部。支持新增和删除状态。

**道具**：每个道具一行，通过编辑弹窗修改所有字段，支持资产图生成。

**分镜**：每集一行，点击展开显示该集所有分镜片段的原始识别文本与本地化转化文本（左右对照）。支持批量转化和跳转分镜内容生成。

### 3. 分镜内容生成界面

左侧集数选择，右侧为该集的分镜片段卡片列表。

- **全选/勾选**：顶部全选 + 每张卡片独立勾选，批量生成仅处理已勾选片段
- **分镜提示词**：可编辑的完整生成提示词
- **参考资产**：关联的角色+场景资产图缩略图，支持添加和删除
- **参考资产选择弹窗**：四 Tab（角色服装/场景/道具/生成结果），多选后底部实时显示选择数量
- **视频预览面板**：黑色背景固定高度，新增分镜显示"暂无视频"占位
- **生成配置弹窗**：点击底部参数摘要按钮弹出，含模型 Tab 切换（即梦/Vidu/奇智）和按钮式选项（模型版本、画幅比、分辨率、音画同步、视频时长、生成数量）
- **卡片交互**：拖拽排序、卡片间插入新分镜（自动编号）、删除分镜（自动重编序号）
- **全集预览**：可拖动的浮动视频弹窗，关闭时自动暂停

## 技术栈

纯静态前端 Demo，无后端依赖。

- HTML5 + CSS3 + Vanilla JS
- CSS Variables 主题系统
- Flexbox / Grid 响应布局

## 本地预览

```bash
# 方式一：直接打开
open index.html

# 方式二：本地服务（推荐，避免 CORS 问题）
python -m http.server 8080
# 访问 http://localhost:8080
```

## 数据说明

Demo 中展示的数据来源于一部 65 集中文短剧的真实识别与转化结果：

- 37 个角色（主要角色 2 个，次要角色 35 个）
- 33 个场景
- 842 个分镜片段
- 角色服装：女主角 31 套、男主角 23 套
- 目标市场：欧美方向
